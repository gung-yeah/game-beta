# 골든 라이프 — 베타 테스트

퍼즐을 풀고 강아지를 돌보는 모바일 웹 게임의 베타 테스트 저장소입니다.

- 플레이: https://gung-yeah.github.io/game-beta/
- 사람 테스터 피드백: 게임 안 메뉴(☰) → 「💬 피드백 보내기」
- **테스터 AI**: `AGENTS.md`와 `qa/README.md`를 먼저 읽고, 결과는 `qa/reports/`에 남깁니다.

| 파일 | 내용 | 누가 바꾸나 |
|---|---|---|
| `index.html`, `manifest.webmanifest`, `icon-*.png` | 빌드된 게임 | 개발 AI만 (베타를 올릴 때) |
| `qa/` | 테스트 안내·양식·보고서 | 테스터는 `qa/reports/` 안 자기 회차 폴더에만 씁니다 |

이 저장소와 GitHub Pages는 공개되어 있습니다. 보고서에 개인정보를 넣지 마세요.
