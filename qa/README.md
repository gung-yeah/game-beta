# 테스터 안내 (QA)

## 1. 역할
- 당신은 **테스터**입니다. 게임을 직접 실행하고, 본 것을 **보고만** 합니다: 오류(버그), 개선점, 건의.
- 게임을 만들고 고치는 것은 개발 AI가 합니다. 다음은 하지 않습니다.
  - `qa/reports/<내 회차 폴더>/` 밖의 파일 만들기·고치기·지우기 (`index.html`, 아이콘, `qa/README.md`, 양식, 다른 회차 폴더 모두)
  - 코드 수정 파일(패치·diff) 올리기. 고칠 방법이 떠오르면 보고서의 `suggestion`에 **글로** 적습니다.
- 사람이 잡기 어려운 것을 특히 봐 주세요: 여러 화면 크기·방향, 같은 동작 반복 재현, 콘솔 오류, 숫자(보상·확률·난이도)가 설명과 맞는지, 새로고침 뒤 저장, 글자 잘림·겹침, 맞춤법·조사.

## 2. 회차 시작
1. 게임 시작 화면의 **「🧪 베타 테스트 vX.Y.Z」** 로 버전을 확인합니다.
2. 회차 폴더를 만듭니다: `qa/reports/<YYYY-MM-DD>_v<버전>_<테스터 이름>/` (예: `qa/reports/2026-10-21_v4.13.0_ai-1/`)
3. `qa/templates/`의 양식을 복사해 `QA_REPORT.md`, `BUG_REPORT.json`을 채우고, 증거는 `evidence/`에 넣습니다.
4. 이전 회차 폴더가 있으면 그 `BUG_REPORT.json`의 버그가 고쳐졌는지 다시 확인해 `retest`에 적습니다.

## 3. 게임 실행
- 주소: https://gung-yeah.github.io/game-beta/ (빌드된 한 파일. 서버·로그인 없음)
- **처음부터 하기**: 새 브라우저 프로필(시크릿 창)로 열거나, 개발자 도구에서 `localStorage.clear()` 후 새로고침
- 저장은 브라우저 `localStorage`에만 있습니다.
  - `golden-life/meta/v1` — 게임 진행 전체 (JSON). 버그 증거로 이 값을 `evidence/BUG-xxx_save.json`에 저장해 주세요
  - `golden-life/beta-welcome-v*` 환영 안내를 봤는지, `golden-life/sound` 효과음·진동 설정, `golden-life/rotate-dismissed*` 방향 안내
- 주소 옵션
  - `?mode=puzzle` — 처음 화면을 건너뛰고 강아지 방으로 (입양 전이면 입양부터)
  - `?debug` — 자동화용 손잡이
    - 퍼즐 중 `window.__pz`: `phase()`(intro·play·bonus·won·lost), `busy()`, `state()`, `move()`(둘 수 있는 수 하나), `at(r, c)`(칸의 화면 좌표), `charge()`(도우미 게이지), `skill()`(도우미 기술 쓰기)
    - 외출 중 `window.__td`: `regionId()`(town·park·clinic·petshop), `isBusy()`, `travelTo(id)`, `goTo(대상 id)`(예: `vet`, `bench`, `shop_counter`, `fetch`, `npc_dog`, `npc_tip`), `toScreen(x, y)`(지도 칸 → 화면 좌표), `playerTile()`
- 강아지 방 메뉴(☰) → 「🧪 테스트용 도구」: 하트 가득·별 5개·뼈다귀 200개·합성 판수 채우기·모든 단계 열기. 사용했다면 보고서에 적어 주세요.
- 소리는 브라우저가 화면을 한 번 누른 뒤에만 납니다(웹 오디오). 효과음·진동은 메뉴에서 끌 수 있습니다.

- [ ] 이야기(돌봄 과제): 장면 넘기기, 선택지, 알아두기, 상태 변화, 새 기술 카드

## 5. 보고서 쓰는 법
### BUG_REPORT.json (개발 AI가 읽음)
- 형식: `qa/BUG_REPORT.schema.json`, 빈 양식: `qa/templates/BUG_REPORT.json`
- 버그 id는 회차 안에서 `BUG-001`부터, 건의는 `IDEA-001`부터
- 버그 하나에 하나의 문제만. 재현 단계는 처음 상태부터 숫자 순서로, 화면 크기·방향·밝기 모드를 꼭 적습니다
- 심각도
  - `critical` 게임이 멈추거나 진행 불가, 저장이 날아감
  - `major` 기능이 틀리게 동작(보상이 안 들어옴, 버튼이 안 눌림), 화면 크기 하나에서 중요한 버튼이 가려짐
  - `minor` 불편·어색함(글자 잘림, 겹침, 조사 틀림)
  - `trivial` 아주 작은 것
- 같은 문제가 이전 회차에도 있었으면 `seen_before`에 `<회차 폴더>/BUG-xxx`

### QA_REPORT.md (사람이 읽음)
`qa/templates/QA_REPORT.md` 양식대로. 요약, 테스트 범위, 게임성 점수와 이유, 영역별 메모, 버그 요약 표, 건의.

### evidence/
- 이름: `BUG-001_1.png`, `BUG-001_2.png`, `BUG-001_console.log`, `BUG-001_save.json`, `BUG-001_steps.log`(자동화 로그)
- 화면 사진은 문제가 보이는 부분이 잘 드러나게. 큰 동영상은 넣지 않습니다(10MB 이하)

## 6. 올리기
```
git pull --rebase
git add qa/reports/<내 회차 폴더>
git commit -m "QA: <YYYY-MM-DD> v<버전> <테스터 이름>"
git push
```
`git add -A`는 쓰지 않습니다 (다른 파일이 섞이지 않게).
